Entry for make.fun's **"Office Artifacts: The One-Line Placard Contest"**. The program writes a single original one-line museum placard (140 characters) — an ordinary office paperclip labelled as an ancient artifact — to `/output/entry.txt`:

> Paperclip, bent wire, c. 1899. Bound a thousand-page treaty, then bent once and never straightened. On loan from the Ministry of Loose Ends.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
